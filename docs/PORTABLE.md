# Windows 便携版（发布后）

> 当前尚未发布便携包；以下是正式 Release 的目标流程。

1. 下载 `SkillLibraryMini-Windows-Portable-x64.zip`。
2. 解压到可写入的普通文件夹。
3. 双击 `SkillLibraryMini.exe`。

请不要直接在 ZIP 内运行程序。便携版不需要安装开发环境，也不要求 Node.js、npm、Rust 或编译器。

便携版仍使用系统用户数据目录保存个人状态，不会把收藏或最近查看写入发布包本身。Skill 扫描路径与安装版一致，详见 [Windows 安装说明](INSTALL_WINDOWS.md)。
